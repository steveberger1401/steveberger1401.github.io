# Bewerberwebseite · Steve Berger

Einseitige Webseite (HTML/CSS, keine Abhängigkeiten), gehostet über GitHub Pages.

## Lokal ansehen

Einfach `index.html` im Browser öffnen.

## Auf GitHub veröffentlichen

1. Auf GitHub ein neues Repository anlegen. Für die Standard-Adresse heißt es am besten `<benutzername>.github.io`.
2. Die Datei `index.html` ins Repository hochladen (Branch `main`).
3. Im Repository unter **Settings → Pages** als Quelle **Deploy from a branch** wählen, Branch `main`, Ordner `/ (root)`.
4. Nach wenigen Minuten ist die Seite unter `https://<benutzername>.github.io/` erreichbar.

## Vor dem Veröffentlichen prüfen

- Die Kontaktdaten sind öffentlich. Telefonnummer ist bewusst nicht enthalten.
- Keine Passwörter, Tokens oder internen Adressen in Repository und Seite.
- Projekt-Links im Abschnitt „Projekte“ sind noch nicht verlinkt.
