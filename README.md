# Steve Berger · Bewerberwebseite

Einseitige Webseite mit Profil, Berufserfahrung, Kompetenzen, Projekten und Kontakt.
Umgesetzt mit HTML und CSS, ohne Abhängigkeiten, gehostet über GitHub Pages.

**Live:** https://steveberger1401.github.io/

## Inhalt

- Berufserfahrung und Weiterbildung
- Kompetenzen (Cloud, Modern Workplace, Security, Microsoft 365, Automatisierung)
- Eigene Projekte, u. a. ein Familienkalender mit [Live-Demo](https://family-demo.pinky-ha.de) und [Video](demo-video.mp4)

## Lokal ansehen

`index.html` im Browser öffnen. Das Demo-Video `demo-video.mp4` muss dafür im selben Ordner liegen.
